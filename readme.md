# Распространение тепла в триангуляции
### Задача
Решить уравнение теплопроводности на однородной прямоугольной плоскости. Сетку на плоскости задать триангуляцией Делоне, численным методом выступает метод конечных элементов.
### Сборка
Сборка осуществляется через cmake.
### Работа с программой
Взаимодействие с программой осуществляется через класс `SolutionController`, в качестве параметров инициализации он принимает:
1. Число вершин триангуляции
2. Параметры пластины: ширина, высота, коэффициент температуропроводности, начальные температуры
	1. Начальные температуры: температура плоскости, температура на левой границе, температура на правой границе, температура на верхней границе, температура на нижней границе
Программа начинает выполнение сразу же после инициализации класса контроллера.
### Результат работы
Результатами работы программы являются
1.Бинарный файл `num_result.bin` в папке сборки проекта, внутри файла сериализован класс `DTO::AllDataResult`, который представляет из себя запись по всем кадрам (шагам по времени, частота записи задаётся к константах) и прочую полезную информацию. Предназначен для передачи в программу отрисовки
2.Два файла с данными для построения графиков. Находятся в директории `Plots`. Графики можно создать вызвав gnuplot скрипты в соответствующей папке. Есть два вида графиков: график максимальной разности температур на момент времени t и средне квадратичное отклонение температур на момент времени t.


#### Пометки
коэффициент температуропроводности  - да, именно температуропроводности, не теплопроводности, см. гугл.
